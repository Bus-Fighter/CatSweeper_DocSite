    踩地雷玩法

    Reference Game：傳送門

    UI請移玉步到Stage UI

    Item

    Fever Mode

    玩法介紹

    • 場上地雷（Mine）有等級(Mine Level)設定
    • 地圖的格子（grid）會顯示相鄰8格的Mine Level 總和
    • 玩家每場開始時起初始玩家等級（Player level） 為1
    • 玩家點擊地雷時會獲得等同Mine Level的經驗值（EXP）
      • 例如打開Level 1 Mine, 會獲得EXP 1
      • EXP滿時Player Level會級升
      • 每個Player Level的升級所需EXP視每場的Mine數量而定，詳看map setting
    • 每場起始有3 HP （global variable, 可在gameSetting調整）
      • 當玩家打開Mine Level > Player Level的Mine，會扣除HP
    • 打開格子時如為空格（Empty Grid）, 會一併打開相連的空格及其外圍一圈的數字

    打開地雷

    • 當打開的格子為地雷時，地雷會從地圖中消失，附近的數字會更新
    • 如Player Level ≥ mine level: 主角要有一個捉起貓貓聞嘅animation
    • 如Player Level < mind level: 要有貓貓抗拒主角嘅animation, e.g.貓爪、跑走、叫 etc
      • 並會扣一格HP

    遊戲勝利條件

    • 成功找出所有地雷
    • （TBC）Player Level已達到最高Level / 場上沒有mine level > player level的mine

    失敗條件

    • 玩家HP歸0 時失敗，彈出Lose UI

    • 每次進入關卡會根據info setting隨機生成地圖
    • 會隨機選擇一個空格為安全格（即不是地雷格或數字格），顯示指示UI，指引玩家作為安全的第一步
      • 玩家可以不按這個安全格，若玩家一直不按，指示UI會一直存在，直到被玩家按下、被標記或已打開
    • 地圖採取no guessing 規則生成(現階段先不處理)
      • 如果做唔到no guessing（棄用）
        • 至少做起始 buffer步數，startingBufferLimit個value designer喺game setting到set
        • 然後入關卡時random 1-startingBufferLimit, 抽到嘅數字代表buffer步數
          • 例如抽到3，即代表頭3下都唔會爆，之後先gen個地圖出嚟
        • 同個map可以70%以上唔洗靠估嚟贏

    Player Level Table

    • 會有一個default設定嘅table, 如果係用default，每Level升級需求就係場上該level有嘅地雷數目，Max Level就係等如場上最高Mine Level嘅地雷

    • 例如場上有10個level 1， 5個level 2，2個level 3，咁level 1 就係要10點EXP，Level 2就係5點EXP，最大等級就係3

      keyId default
      level EXP
      1 MineLevelCount(0)
      2 MineLevelCount(0)
      3 MineLevelCount(0)
      4 MineLevelCount(0)

    • MineLevelCount(0)嘅意思係該場上相同Level地雷數量 +- 0

      • 假如Level 1填MineLevelCount(-1)，代表場上level 1的mine總和-1，即如果場上有10個level 1 mine，level 1 升level 2所需EXP為9

    地雷設定（Mine Setting）

    mineId string
    iconName string 於關卡中顯示的icon
    mineLevel int
    displayName string localisation
    prefabPath path 於關卡中顯示animation用
    uiModelPath path 在主畫面/圖鑑用
    revealReward Command string 成功打開地雷時的reward
