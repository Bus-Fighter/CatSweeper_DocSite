    GameDebuggerUtil - JSON ↔ Variant Conversion

    Overview

    GameDebuggerUtil provides bidirectional conversion between JSON objects and Godot Variants, enabling seamless data exchange between C# and Godot types.

    Features

    ✅ Convert Godot → JSON

    • Converts Godot Variants to JSON-serializable objects
    • Handles Vector2, Vector2I, Dictionary, Array
    • Preserves type information where possible

    ✅ Parse JSON → Godot

    • Reconstructs Godot Variants from JSON objects
    • Auto-detects Vector2/Vector2I from {x, y} objects
    • Supports System.Text.Json.JsonElement
    • Handles nested structures

    API Reference

    Godot → JSON Conversion

    // Convert a single Variant to JSON object
object ConvertVariantToJson(Variant variant)

// Convert Godot Array to object[]
object[] ConvertArrayToJson(Godot.Collections.Array array)

// Convert Godot Dictionary to C# Dictionary
Dictionary<string, object> ConvertDictionaryToJson(Godot.Collections.Dictionary dict)

    JSON → Godot Conversion

    // Parse JSON object to Variant
Variant ParseJsonToVariant(object jsonObj)

// Parse JSON array to Godot Array
Godot.Collections.Array ParseJsonToArray(object[] jsonArray)

// Parse JSON dictionary to Godot Dictionary
Godot.Collections.Dictionary ParseJsonToDictionary(Dictionary<string, object> jsonDict)

    Usage Examples

    Example 1: Convert Godot Data to JSON

    // Godot data
var position = new Vector2I(10, 20);
var data = new Godot.Collections.Array { position, "player", 100 };

// Convert to JSON
var jsonArray = GameDebuggerUtil.ConvertArrayToJson(data);
var json = JsonSerializer.Serialize(jsonArray);

// Result: [[{"x":10,"y":20},"player","100"]]

    Example 2: Parse JSON back to Godot

    // JSON data
var json = """{"x": 10, "y": 20}""";
var jsonObj = JsonSerializer.Deserialize<Dictionary<string, object>>(json);

// Convert to Godot Variant
var variant = GameDebuggerUtil.ParseJsonToVariant(jsonObj);
var position = variant.AsVector2I(); // Vector2I(10, 20)

    Example 3: Complex Nested Data

    // Godot data with nested structures
var gameState = new Godot.Collections.Dictionary
{
    ["player"] = new Godot.Collections.Dictionary
    {
        ["position"] = new Vector2(100.5f, 200.3f),
        ["health"] = 100,
        ["inventory"] = new Godot.Collections.Array { "sword", "shield" }
    },
    ["level"] = 5
};

// Convert to JSON
var jsonDict = GameDebuggerUtil.ConvertDictionaryToJson(gameState);
var json = JsonSerializer.Serialize(jsonDict);

// Parse back to Godot
var parsedDict = JsonSerializer.Deserialize<Dictionary<string, object>>(json);
var godotDict = GameDebuggerUtil.ParseJsonToDictionary(parsedDict);

    Example 4: Working with JsonElement

    // Receive JSON from WebSocket
var jsonText = """{"position": {"x": 50, "y": 100}, "name": "Player"}""";
var document = JsonDocument.Parse(jsonText);

// Convert JsonElement to Variant
var variant = GameDebuggerUtil.ParseJsonToVariant(document.RootElement);
var dict = variant.AsGodotDictionary();

// Access nested data
var positionVariant = dict["position"];
var position = positionVariant.AsVector2I(); // Vector2I(50, 100)

    Type Conversion Table

    Godot Type JSON Representation Notes
    Vector2I(10, 20) {"x": 10, "y": 20} Integer coordinates
    Vector2(10.5, 20.3) {"x": 10.5, "y": 20.3} Float coordinates
    Dictionary { "key": value } Recursive conversion
    Array [item1, item2] Recursive conversion
    string "text" Direct conversion
    int, long, float, double 123, 45.67 Direct conversion
    bool true, false Direct conversion
    null null Default Variant

    Auto-Detection Logic

    Vector2 vs Vector2I Detection

    When parsing {"x": ..., "y": ...} objects:

    1. Vector2I - If both x and y are integers

      {"x": 10, "y": 20} → Vector2I(10, 20)

    2. Vector2 - If either x or y has decimals

      {"x": 10.5, "y": 20} → Vector2(10.5, 20)

    Dictionary vs Vector Detection

    • If object has exactly 2 properties named "x" and "y" → Vector
    • Otherwise → Dictionary

    Integration with GameDebugger

    The utility is used internally by GameDebugger for WebSocket communication:

    // In GameDebugger.SendMessage
var payload = new DebugMessage
{
    Message = "stage_info",
    Data = GameDebuggerUtil.ConvertArrayToJson(data)
};
var json = JsonSerializer.Serialize(payload);
await _client.SendText(json);

    // In GameToolsPlugin.OnMessageReceived
var json = Encoding.UTF8.GetString(socketMessage.data.Span);

    Performance Considerations

    Memory Allocation

    • ConvertToJson: Creates new object arrays/dictionaries
    • ParseToVariant: Creates new Godot collections
    • For high-frequency messages, consider object pooling

    Type Detection Overhead

    • Vector detection requires checking object properties
    • Minimal overhead for most use cases
    • Consider explicit type hints for performance-critical code

    Error Handling

    The utility is designed to be fault-tolerant:

    • Null values: Return default Variant
    • Unknown types: Convert to string via ToString()
    • Invalid structures: Gracefully degrade to simpler types

    Best Practices

    1. Use for WebSocket/Network communication where JSON is required
    2. Avoid for internal Godot-to-Godot communication (use Variants directly)
    3. Validate data types after parsing if type safety is critical
    4. Cache frequently used conversions if performance is a concern

    Future Enhancements

    Potential additions:

    • Support for more Godot types (Vector3, Color, Rect2, etc.)
    • Custom serialization attributes
    • Schema validation
    • Performance optimizations with object pooling
