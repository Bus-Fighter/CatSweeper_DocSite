    Namespace CatSweeper.Stage.NoGuess

    Classes

    LevelThresholdDangerRule

    Default danger rule: a mine is dangerous when its level exceeds the player's current level. This matches the existing catch rule where cats at or below the player's level are safe to catch, and higher-level cats cost HP.

    NoGuessConfig

    Tunables for the no-guess grid generator. Values are read from GameSettingInfo at runtime and can be overridden in tests.

    NoGuessSolver

    Verifies that a generated stage grid is logically solvable without guessing.

    The solver is rule-agnostic: it enumerates all level assignments consistent with the revealed clue sums, and asks the injected IDangerRule whether each hypothetical mine would be dangerous to the player. A board is rejected when a hidden cell's safe/dangerous verdict varies across valid assignments.

    Single-level stages use a fast boolean shortcut (level sums reduce to counts). Multi-level stages use integer-domain constraint propagation with bounds consistency and capped per-constraint tuple enumeration.

    Structs

    PlayerSnapshot

    Minimal snapshot of the player state used by the no-guess solver. The solver verifies solvability from the initial state (level 1, starting HP).

    VerifyResult

    Result of verifying a board with the no-guess solver.

    Interfaces

    IDangerRule

    Configurable rule that decides whether a particular mine is dangerous to the player in their current state. Keeping this behind an interface lets designers review and swap catch semantics without touching the solver.
